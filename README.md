# 📊 Wholesale Customers Clustering

Проект посвящён кластеризации датасета **Wholesale customers data** с целью выделения групп клиентов по схожести их покупательского поведения. В ходе работы выполнялась предварительная обработка данных, поиск оптимального числа кластеров и оценка качества разбиения с помощью нескольких метрик.

---

## Описание проекта

Исходный набор данных содержит информацию о клиентах оптового поставщика. Для построения кластеров были проанализированы числовые признаки, выполнено масштабирование данных, применено логарифмирование для уменьшения влияния выбросов, а также использован метод главных компонент для визуализации результатов.

Основная цель проекта — определить, можно ли разделить клиентов на устойчивые группы и какое количество кластеров является наиболее обоснованным.

---

## Что было сделано

В рамках проекта были выполнены следующие шаги:

* загружен и изучен исходный датасет;
* проверены структура данных, описательная статистика и наличие дубликатов;
* выполнено масштабирование признаков с помощью `StandardScaler`;
* построена двумерная визуализация данных с помощью `PCA`;
* удалены категориальные признаки `Channel` и `Region` для анализа только числовых характеристик;
* применено логарифмирование `log1p` для сглаживания распределений и уменьшения влияния выбросов;
* построен график метода локтя для подбора числа кластеров;
* рассчитаны метрики качества кластеризации:

  * `silhouette_score`;
  * `calinski_harabasz_score`;
  * `davies_bouldin_score`;
* выполнена итоговая кластеризация методом `KMeans`;
* результаты визуализированы на плоскости главных компонент.

---

## Используемые методы

### StandardScaler

Использовался для приведения признаков к единому масштабу, чтобы значения с большим диапазоном не доминировали над остальными.

### Log1p-преобразование

Применялось для уменьшения асимметрии распределений и сглаживания выбросов.

### PCA

Использовался для снижения размерности и наглядного отображения структуры данных в двумерном пространстве.

### KMeans

Основной метод кластеризации, который разбивает данные на группы на основе расстояний до центров кластеров.

### Метрики качества

Для оценки результатов кластеризации использовались:

* **Silhouette Score** — показывает, насколько хорошо объекты отделены от других кластеров;
* **Calinski-Harabasz Score** — измеряет соотношение межкластерного и внутрикластерного разброса;
* **Davies-Bouldin Score** — оценивает степень похожести кластеров друг на друга.

---

## Выбор числа кластеров

Сначала был построен график метода локтя, по которому рассматривались несколько возможных вариантов, в том числе `k = 2` и `k = 3`.

После расчёта метрик качества выяснилось, что:

* `silhouette_score` лучше всего показывает результат при `k = 2`;
* `calinski_harabasz_score` также максимален при `k = 2`;
* `davies_bouldin_score` в некоторых случаях немного лучше оценивал разбиение на 3 кластера, однако разница была небольшой.

С учётом всех результатов было принято решение остановиться на **2 кластерах** как на наиболее обоснованном варианте.

---

## Итог работы

В результате предварительной обработки данные стали более пригодными для кластеризации. Применение логарифмирования и стандартизации помогло сделать структуру признаков более выразительной, а визуальный анализ и метрики качества показали, что наиболее устойчивое разбиение достигается при `k = 2`.

Таким образом, проект позволил выделить две основные группы клиентов, отличающиеся по характеру покупательской активности.
